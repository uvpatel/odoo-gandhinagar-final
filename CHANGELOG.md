## Versioning

PeoplePay360 uses semantic versioning where practical:

```text
MAJOR.MINOR.PATCH
```

Example:

```text
1.2.3
```

Where:

* `MAJOR` represents breaking changes.
* `MINOR` represents backward-compatible functionality.
* `PATCH` represents backward-compatible fixes.
